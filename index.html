Verification Commands

Boot a Ubuntu Server 24.04 USB stick on the machine before paying. Run each command, tick it off, and compare against the expected output. If the vendor won't let you test, walk away.

1 CPU — confirm the chip
lscpu | grep "Model name"
# Expected: Intel(R) N100 / N150  —or—  AMD Ryzen 7 5700U
2 RAM — capacity & speed
free -h
sudo dmidecode -t memory | grep -E "Size|Speed|Type"
# Expected: 8/12/16GB, DDR4-3200 or DDR5-4800
# Watch for: soldered RAM (no SO-DIMM slot = no upgrade)
3 Storage — capacity & brand
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT
# Expected: advertised capacity
# Note: is it Samsung / WD / Kingston, or a no-name SSD?
4 GPU — transcoding support
lspci | grep -i vga
# Intel: Alder Lake-N [UHD Graphics]
# AMD:   Radeon Vega 8
5 Network — Ethernet ports
ip link show
# Expected: at least one eth0, ideally 2.5G
# Red flag: Wi-Fi only, no Ethernet
6 BIOS — Secure Boot toggle
sudo mokutil --sb-state
# Or: reboot, press DEL / F2, check Secure Boot is toggleable
# Required for Ubuntu Server on some OEM boards

🚩 Red flags — walk away if any of these are true

  • Specs don't match lscpu or free -h output
  • No-name SSD with no brand marking on the label
  • Soldered RAM with no SO-DIMM slot (can't upgrade later)
  • Wi-Fi only, no Ethernet port at all
  • BIOS locked — can't disable Secure Boot
  • Vendor refuses to let you boot a USB stick
  • Price for a branded 16/512 box exceeds €180

Negotiation Cheat Sheet

  • Start at 80% of listed price. Huaqiangbei vendors expect haggling — the first price is never the real price.
  • Anchor with ZOL prices. Say "GMKtec G2 is ¥1,088 on ZOL" — this sets the floor and shows you've done homework.
  • Bundle RAM + SSD + barebone for a discount if you go the barebone route. Vendors often have margin to move on bundles.
  • Walk away if the price doesn't move. There are 50 more stalls selling the same thing within 100 meters.
  • Cash (RMB) gets better prices than WeChat Pay at some stalls. Bring both, and don't show your full wallet.

If something goes wrong
